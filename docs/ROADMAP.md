#### 論点1: 商用利用 — **保留（2026-08-14 判断）**

**商用の予定なし。現時点では問題としない。完成後に再検討する。**

#### 論点2: 「再配布 / 二次頒布の禁止」と実装方式の衝突

**Moiky氏と一止月サノツキ氏を除く全作者が再配布・二次頒布を禁止している。**

- 本プロジェクトの立ち絵は `tools/psd_extract.cjs` で PSD をレイヤー分解し、パーツPNG を `public/characters/parts/` に配置してランタイム合成する方式（KNOWLEDGE §17）
- ゲームを配布すると、**分解済みパーツPNG がそのまま利用者の手に渡る**。これが「再配布」「二次頒布」「改造したものの配布」に該当するかは規約文言からは判断できない
- Moiky氏は「動画外利用を制限しない・改変自由」と明記、一止月サノツキ氏は「ゲーム作品での金銭発生も可・再配布時は最新版readme同封」と条件が明示されており、この2氏については論点が小さい
- **対応の選択肢**: 各作者への直接確認 / 該当キャラのみ分解せず1枚絵として使う / 素材の差し替え

#### 論点3: 一止月サノツキ氏 readme の第三者解説禁止

同氏 readme に「このreadmeを第三者に解説しないこと」の条項があるため、本書には要点のみ記載し原文を転記していない。**作業前に素材フォルダ内の readme.txt 原文を必ず直接読むこと。** また同素材は「利用前に最新バージョンか確認し、最新版 readme に従うこと」が求められているため、着手時点でニコニコ静画（https://seiga.nicovideo.jp/seiga/im11401412 ）を確認する。

**いずれも着手前に人間が判断すること。** AI 側では結論を出さない。
