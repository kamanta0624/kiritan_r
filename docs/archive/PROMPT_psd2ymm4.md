# PROMPT: psd2ymm4 — PSD → YMM4形式 変換ツール

対象: ClaudeCode
作成: 2026-08-19
前提ドキュメント: `KNOWLEDGE.md`, `docs/DESIGN_PORTRAIT_SCALE.md`

## 0. 背景（これは調査済みの事実。再調査するな）

立ち絵素材が6作者ぶん手元にある。Moiky氏の43体だけがYMM4形式のフォルダを同梱しており、
残る作者はPSDのみ。**素材の中間形式をYMM4形式に統一する**方針が決まっている。

現行の `public/characters/parts/<char_key>/rig.json` は、表示するレイヤーIDを
人間が手書きしている。char_006 と char_017 の2体しか無い。100体分の手書きは非現実的。
YMM4形式の `preset.ini` は作者が用意した表情プリセット（きりたんで231通り）を含むため、
これを取り込めば手書きが消える。

**このプロンプトの範囲は変換ツールのみ。ゲーム側の描画コードは一切触るな。**
ADVScene のローダ差し替えは別プロンプトで行う。


`public/characters/parts/` は既存の char_006 / char_017 が使用中。**触るな。**

## 2. 既存コードの再利用（コード根拠）

`tools/psd_extract.cjs`（294行・依存パッケージゼロ）に以下が実装済み。流用しろ。

- PSDヘッダ／レイヤーレコードのパース
- `luni`（Unicodeレイヤー名）と `lsct`（セクション種別）の読み取り
- RLE/生データのチャンネル展開
- 独自PNGエンコーダ `encodePng(rgba, w, h)`

不足している機能は §4 の2点のみ。

**注意**: `psd_extract.cjs:103-111` の `groupPath` 構築は、レイヤーを配列先頭から
走査して `isGroup` でpush・`isGroupEnd` でpopしている。PSDのレイヤーレコードは
下から上の順で格納され、グループの開始マーカー（`lsct`=1 or 2、名前を持つ）は
子より**後**、終了マーカー（`lsct`=3）は子より**前**に来る。
新ツールでは**配列を逆順に走査**してツリーを組め。

## 3. YMM4形式の仕様（Moiky素材の実測結果）

```
<charKey>/
  preset.ini
  後/  体/  口/  目/  眉/  顔色/  髪/  他/
```

- 必須カテゴリ（体・口・目・眉・顔色）はMoiky 43体すべてに存在
- 任意カテゴリ: 他39体 / 髪26体 / 後10体
- `preset.ini` は **UTF-8 BOM・CRLF**

```ini
[会話用＿怒り]
眉=怒り.png
目=驚き.png
口=口パク歪み.png
顔色=赤面.png
他1=エフェクト＿怒りマーク.png
```

- キーはカテゴリ名。同カテゴリ複数指定は `他1` `他2` `後1` のように連番
- Moiky実測のキー出現数: 眉231 / 目231 / 口229 / 顔色95 / 体74 / 髪33 / 他1:26 / 後1:10 / 他2:2

**描画順**（PSDのレイヤーID昇順＝背面→前面で実測。推測ではない）:

```
後 → 髪(後) → 体 → 口 → 目 → 眉 → 顔色 → 髪(前) → 他
```

## 4. 実装すべき機能（既存ツールに無いもの）

### 4-1 グループのフラット化

作者によっては「1つの表情差分」が単一レイヤーではなく**グループ**になっている。
このグループ内の子レイヤーをアルファ合成して1枚のPNGにしろ。

該当が確認済みの作者:

- MtU — `表情/目/*通常` などが7レイヤー前後のグループ
- ぱるとねる — `*目まとめ/*普通目` がグループ
- 一止月サノツキ — `!手前腕/*ピース` がグループ

合成は通常のsource-overアルファ合成でよい。レイヤーの `blend` が `norm` 以外の
ものが出た場合は**警告を出して norm として処理し、ログに残せ**（乗算等の再現は範囲外）。

各レイヤーはPSD内で `left/top/w/h` を持つ。合成時はキャンバス座標系で重ねること。
出力PNGはバウンディングボックスにトリムせず、**PSDキャンバス全体のサイズ**で出せ。
（YMM4がそう扱う。座標オフセットを別途持たせない）

### 4-2 preset.ini の生成

PSDには表情プリセットの情報が無い。以下で生成しろ。

- 各カテゴリのデフォルト = PSDで `visible=true` のレイヤー（＝作者が想定した標準状態）
- セクション `[デフォルト]` を1つ作り、上記の組み合わせを書く
- 目・口・眉のバリエーションごとに `[目_<名前>]` `[口_<名前>]` 形式で単一カテゴリのみ
  上書きするセクションを機械生成する

**PSDから作者の意図した「表情セット」は復元できない。プリセットの組み合わせを
勝手に発明するな。** 単カテゴリ差分のみ列挙し、組み合わせは後工程（人間か別ツール）に残せ。

Moiky素材（既にYMM4形式）はこのツールの対象外。変換せずそのままコピーして使う。

### 5-0 マッチング方式（フルパス一致にするな）

同一作者内でも階層の深さとラップの有無が違う。**フルパス一致では破綻する**（§5-2 参照）。
以下の方式で実装しろ。

1. レイヤーツリーを上から走査する
2. グループ名から接頭辞 `*` `!` `＊` を除去した文字列が map のキーに一致したら、
   そのグループを**カテゴリ境界**とする
3. カテゴリ境界の**直下の各要素**（レイヤーでもグループでも）が1差分。
   グループの場合は §4-1 でフラット化して1枚のPNGにする
4. カテゴリ境界より深い階層で再びキーにヒットしても無視する（最も浅い祖先が勝つ）
5. どのカテゴリ境界にも属さないレイヤーは未分類として除外し、警告ログに出す

**mapのキーは必ず単一のグループ名で書く。`親/子` の複合キーも `!` `*` の接頭辞も書くな。**
同一作者内でラップの有無が違う実例が2件確認されている（§5-1 shinobi / §5-2 mtu）。
複合キーは祖先の存在を要求するため、ラップの無い個体で必ず落ちる。

この方式なら MtU の `千冬/体/制服`（体が境界）と `花梨/制服`（制服が境界）が
どちらも `体` カテゴリのPNGを産む。粒度は違うが成功基準2は満たす。

**未probeのPSDがある。作者ごとに全PSDを走査してマッピングの網羅性を検証しろ。**
マッピングに載っていないグループが出たら **エラーで落とさず警告ログに出し、
`他` に入れず未分類として除外**すること。

### 5-3 ぱるとねる6体は語彙が全キャラで違う（2026-08-19 実測により確定）

同一作者内どころか**キャラごとに語彙が別物**。全6体を変換対象とし、
§5 の partonelle エントリに全語彙を列挙してある。スキップするな。
該当は char_063 アメノ / char_062 アルマ / char_060 アンジー /
char_058 クロワ / char_061 ディア / char_057 リリン。全員さいたま（ボイボ寮）所属。

実測した語彙の異名:

| カテゴリ | 出現した語彙 |
|---|---|
| 眉 | 眉まとめ / 眉_まとめ / 眉 |
| 目 | 目まとめ / 目_まとめ / 目 / 目（通常）/ 目（デフォルメ）/ 目_デフォルメ |
| 口 | 口まとめ / 口_まとめ / 口 |
| 顔色 | 頬 / ほほ / 頬の赤み |
| 体 | 素体 / !素体 / 素体差分 / 衣装 / 服 / 右手 |
| 髪 | 髪型 |
| 他 | その他効果 / その他 / 涙パーツ / なみだ【微調整用】/ 顔の影、汗 / 髪飾り |

**髪飾り は `他` に入れる。`髪` ではない。**
根拠: YMM4の `髪` は髪型差分の排他選択カテゴリ（preset.ini で `髪=xxx.png` は1つ）。
髪飾りを `髪` に入れると髪型を切り替えた瞬間に髪飾りが消える。
`他` は `他1` `他2` の連番で複数同時指定できる（Moiky実測: 他2まで存在）。

リリンの `!表情差分まとめ` は §5-0 のルール4に抵触しない。
このグループ名は map に無いためカテゴリ境界にならず、その直下の
`目` `口` `眉` `頬の赤み` `なみだ【微調整用】` `顔の影、汗` が境界になる。
**ルール4を変更するな。**

`目（通常）` と `目（デフォルメ）` はクロワで併存する。どちらも `目` に写すと
同名ファイルが衝突する可能性がある。**衝突したらエラーで落とさず、
後勝ちにせず、ファイル名に親グループ名を前置して退避し、警告ログに出せ。**

## 6. 成功基準

以下がすべて満たされた状態を達成するまでループしろ。達成の確認まで自分でやれ。

1. `node tools/psd2ymm4.cjs <psd> <charKey> <author>` が §5 の表の**全PSD**で
   エラー終了しない（しのびぃ〜EX系3体は §5-1 により対象外）
2. 出力ディレクトリが §3 のカテゴリ構造を持ち、必須カテゴリ（体・口・目・眉）の
   PNGが1枚以上ある
3. 出力PNGがすべてPSDキャンバスと同一の幅・高さである
4. `preset.ini` が UTF-8 BOM + CRLF で、`[デフォルト]` セクションを含む
5. グループをフラット化した差分（MtU・ぱるとねる・サノツキ）が、
   単一レイヤーではなく**合成済み**の1枚になっている
   — 検証: 目のPNGが白目・黒目・ハイライト・まつげを含む見た目になっているか、
     ファイルサイズと不透明ピクセル数で判定できる。目視でなく数値で確認しろ
6. 未分類グループの警告ログが標準エラーに出る
7. 既存の `public/characters/parts/` と `src/` に変更が無い（`git status` で確認）
