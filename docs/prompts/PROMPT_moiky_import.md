## 4. portrait.json の生成

`PROMPT_portrait_json.md` §2 のスキーマに従う。**変換はするな。コピーしたPNGをそのまま使う。**

### 4-1. `preset.ini` の読み取り

Moiky の `preset.ini` は **UTF-8 BOM・CRLF**。セクション名は作者ごとにバラバラ。
実測した頻度（43体・全セクション）:

```
35 [会話用＿怒り]  28 [会話用＿普通]  25 [会話用＿泣き]
16 [会話用＿笑い]  12 [会話用＿喜び]   5 [会話用＿悲しみ]
 4 [立ち絵用]      4 [会話＿怒り]      3 [会話用＿煽り]
```

**`[デフォルト]` は存在しない**（`psd2ymm4.cjs` が生成していたもの）。
全セクションを `presets` に転記しろ。

### 4-2. `default` の決定

以下の優先順で決めろ。ヒューリスティックだが、QA画面で全数を目視して直せる。

1. `[立ち絵用]` セクションがあればそれ
2. `[会話用＿普通]` があればそれ
3. `[会話＿普通]` があればそれ
4. セクション名に「普通」を含む最初のもの
5. 最初のセクション

`体` は preset.ini の多くのセクションで省略されている（`体=` の出現は231キー中74）。
`default.体` が上記で決まらない場合:

1. その体の全セクションの `体=` 値のうち**最頻値**
2. 出現ゼロなら `体` フォルダのファイル名**昇順の先頭**

同様に、`default` に指定の無いカテゴリは各カテゴリのファイル名昇順の先頭を採れ。
ただし `他` `後` は**省略しろ**（エフェクト・小物はデフォルトOFFが標準）。

### 4-3. body 測定

`PROMPT_portrait_json.md` §3 と同じ。**体カテゴリの全PNGを測り、最大 height を `body` とする。**
`bodyCandidates` も併記しろ。Moiky の `体` は最小7枚・最大59枚ある（実測）。

## 5. PX_PER_CM の決定

取り込み後、`npm run dev` で `?qa=portrait` を開き、URLを人間に伝えて止まれ。
**Playwright を使うな。目視は人間がやる。**

人間が決めた `PX_PER_CM` の値を受け取ってから、`src/shared/portraitScale.js` の
既定値に焼き込め。localStorage 経由の仕組みは QA用として残していい。
