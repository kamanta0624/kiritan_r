# PROMPT_demo_events_rebuild

体験版のイベントを全面的に作り直す。既存41件は**全破棄**。新規19件を作る。

**前提**: `PROMPT_demo_data_reset` / `PROMPT_engine_base_attack_ctx` /
`PROMPT_engine_forced_opening_battle` の3件が完了していること。未完了なら先にそちらを済ませろ。

---

## 成功基準

1. `src/game/data/events/` 配下に本書の19件だけが存在する
2. `_index.json` が19件ちょうどを列挙し、全 `path` が実在する
3. `npm run dev` で通しプレイでき、オープニング → 旅館防衛戦 → 福島 → 郡山 → 水戸 →
   ボイボ寮宣戦布告（ターン10）まで到達する
4. コンソールに `[EventEngine] unknown condition type` が出ない
5. 上記を自分で通しプレイして確認してから完了報告すること

---

## 手順1. 既存イベントの破棄

`src/game/data/events/` 配下の `_index.json` **以外の全 `.json`（40ファイル）を削除**する。
ディレクトリ `ch03_otaru` / `ch04_saitama_tl` / `ch05_vocalo` / `defeated` は空になるので削除する。
残すディレクトリは `system` / `ch01_tohoku` / `ch02_saitama` / `theater` の4つ。

`_index.json` の `events` 配列は空にしてから、手順2で作る19件を登録し直す。
`_comment` / `_schema` はそのまま残せ。

---

## 手順2. スキーマ

既存イベントと同一。逸脱するな。

```json
{
  "id": "<ファイル名と一致>",
  "name": "<日本語名>",
  "trigger": "<トリガー名>",
  "conditions": [],
  "probability": 1,
  "priority": 500,
  "maxOccurrences": 1,
  "script": [
    { "type": "conversation", "lines": [
      { "characterId": "char_004", "position": "center", "text": "…" }
    ]},
    { "type": "end" }
  ],
  "effects": { "default": [] }
}
```

- `position` は `left` / `center` / `right` のいずれか。同一イベント内で同じキャラは同じ position に固定しろ
- 地の文（キャラのいない演出）は `{ "type": "narration", "text": "…" }`
- 台詞は本書の記載を**一字一句そのまま**書き写せ。要約・言い換え・追記をするな
- 台詞末尾に句点が無いものはそのままにしろ。原文の表記を変えるな

## 6. 検証項目

実装後に自分で確認しろ。

1. `EventEngine._processPlayerTurn`（`EventEngine.js`）が `player_turn` 候補から
   **1件だけ選ぶ実装か、全件発火する実装か**を読んで確認しろ。
   1件だけなら turn 3/6/9/10 のボイボ寮イベントが他の `player_turn` イベントと
   競合しないことを確認する。競合するなら報告しろ。**勝手に仕様を変えるな。**
2. `char_111`（源氏丸）が旅館防衛戦に実際に出現するか。
   `App.jsx:440-446` と `App.jsx:463-469` の敵キャラ抽出は
   `(c.soldiers ?? 0) > 0` でフィルタしている。**`soldiers: 0` の char_111 は除外される可能性が高い。**
   除外されたら実装を変えず、事実を報告しろ。
3. 水戸制圧後に自由都市（`faction_new02`）の拠点が攻撃可能になっているか
