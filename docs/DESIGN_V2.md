## 1. 設計思想

### 1.1 ミームの一元化

ミーム（旧 SP / `soldiers`）はそのキャラの **外付けHP・兵隊・経験値** を兼ねる単一リソース。
別系統で経験値・成長ポイント等を持たない。

### 1.2 内政のメニュー集約

内政画面メニューを4つに集約。それ以外の内政機能はオミット。

- プロモーション（新規）
- クラファン（新規）
- 劇場（既存）
- 仲間（既存・閲覧化）

メニュー外で存続: セーブ / 次のターン / 拠点クリック→BaseMenuScene / 戦闘自動遷移。

### 1.3 内部温存原則

UI 経路のみ削除、データ構造・計算ロジック・JSON は残す。
理由: 復元容易性、セーブ互換、後続フェーズでの再利用余地。

## 2. 廃止 / 温存マトリクス

| 対象 | UI | データ | ロジック | 備考 |
|------|----|----|----|------|
| 研究画面 | 削除 | 温存（events 等の effects 経由参照あり） | 温存 | 設計途中の HOI4 式ツリーも温存 |

| 仲間画面の強化コマンド | 削除（`sp_refill`/`sp_max_up`） | 温存（`upgradeUnlocks`/`purchasedUpgrades`） | 温存 | 仲間画面は閲覧のみに |
| 拠点 income | TopBar 表示削除 | 温存（`income` field） | 温存（内政計算は走らせる or 結果を捨てる） | 通貨廃止と連動 |
| 通貨（treasury） | TopBar 表示削除 | 温存（`treasury` field） | 温存 | 全勢力分の field 維持 |
| 兵力（troops） | MapScene tooltip 削除 / BaseMenuScene StatTile 削除 | 派生値なので元から無し | `MapScene:415` の troops 生成も停止可 | `b.soldiers ?? b.battleCapacity` は内部で生きる |
| SP/`soldiers` フィールド | 表示名「ミーム」に変更（P5） | フィールド名据置 | 据置 | 通貨ミーム廃止後の呼称衝突は解消済 |

### 2.1 「温存」の定義

- データ field / JSON ファイル: 削除しない
- リデューサ / システムクラス: 削除しない
- セーブ互換: SAVE_VERSION 据置可能なら据置（要検証）
- UI からの到達経路: 削除
- 残置物への `@deprecated` コメント付与

## 4. 4メニュー仕様

### 4.1 プロモーション

**機能**: 訓練コマンド。選択キャラのミーム（`soldiers`）を増やす。

**コマンド種別**:

| 区分 | 例 | 対象 | 効果 |
|------|----|------|------|
| 訓練（個別） | 選択キャラを訓練 | 単体 | ミーム加算 |
| 汎用 | 動画収録 / 歌 / 公式素材供給 | TBD | TBD |

**解禁ロジック**: 領地進行に応じて選択肢追加。具体条件は仕様詰めQ参照。

**行動力**: 既存 `actionPoints` プールから消費。消費量は仕様詰めQ参照。

**実装**: 新規 `PromotionScene.jsx`。

### 4.2 クラファン

**機能**: レベルアップ。選択キャラのミームを消費し大幅に強化する。

**第一段階（P3 で実装）**: 未実装ソフトの開発。

**第二段階以降**: 後続フェーズ。本書では枠組みのみ定義。

**データ**: 旧 `DESIGN_software_dev.md` の `software.json` スキーマと `char.engineDev` を流用。配置先 UI のみ仲間画面 → クラファン画面に移動。

**実装**: 新規 `CrowdfundingScene.jsx`、`src/game/data/softwares.json` 新設。

### 4.3 劇場（既存・拡張）

**機能**: キャラクターイベント。1キャラ5イベント、発生条件あり。

**報酬種別**:
- そのキャラのミーム
- プロモーションコマンド解禁
- キャラクリ（周回要素、`KNOWLEDGE.md §17` 未設計）

**メニュー外発生源**: ボイス収録 / グッズ制作 / コラボイベント等。劇場報酬として獲得、回数制限あり。

**現状**: TheaterScene + EventEngine + `events/theater/*.json` で基盤稼働中（Phase 5 統合済）。P4 で報酬種別と発生条件スキーマを拡張。

### 4.4 仲間（既存・閲覧化）

**機能**: 全キャラのパラメータ閲覧。

**削除**: 強化コマンド（`sp_refill` / `sp_max_up`）。クラファン画面に機能移行。

**残置**: 勢力絞込・SP表示・全画面詳細・portrait 表示。

## 5. 用語と呼称

### 5.1 ミーム呼称（P5 で変更）

| 概念 | 旧UI表記 | 新UI表記 | フィールド名 |
|------|---------|---------|------------|

- 「参戦」: `soldiers < battleCapacity` で将軍本体ダメージ可となる状態
- 「戦闘域」: `battleCapacity`

## 6. 行動力

**注意**: `KNOWLEDGE.md` 上は `SAVE_VERSION = 9` 記載、旧 `DESIGN_software_dev.md` は `SAVE_VERSION = 7` 記載で乖離あり。P3 着手時に実コード（`SaveSystem.js`）と再突合せ。
