# 00_UI_REQUIREMENTS — エディタUIのYMM4踏襲化

現行`tools/editor-modules/tab-events.js`（条件・エフェクト・スクリプトのフォーム入力式UI）を廃止し、YMM4（ゆっくりムービーメーカー4）の画面構成を踏襲したUIに置き換える。機能は段階的に拡張する前提で、まず**UI要素の洗い出し**を行う。実装はしない。

参考: https://manjubox.net/ymm4/ 、YMM4実際の画面構成（Wikipedia・複数解説サイトで確認済み）

## YMM4の画面構成（3ペイン、根拠あり）

> 「ゆっくりムービーメーカー4」の画面は大きく3領域に分かれている：①プレビュー ②アイテム（プロパティ） ③タイムライン

1. **プレビュー**：編集結果を確認するキャンバス
2. **タイムライン**：レイヤー×フレームでアイテムを配置する領域
3. **アイテム編集（プロパティ）パネル**：選択中アイテムの詳細設定

## タイムラインの要素（根拠あり）

- **レイヤー**：番号を持つ水平トラック。レイヤー00が最背面、番号が大きいほど前面。レイヤーごとに有効/無効切替可能
- **アイテムブロック**：開始フレーム位置と長さを持つ矩形。ドラッグで移動、境界をドラッグでリサイズ
- **カット（分割）**：再生位置でアイテムを分割する操作（ショートカットCtrl+B相当）
- **隙間検出・削除**：アイテム間の空白を検出し詰める操作
- **グループ化**：複数アイテムを選択してまとめて移動・削除できる状態にする（グループ化解除も可）
- **アイテム検索**：タイムライン上のアイテムをテキストで検索・置換
- **左のアイテムをすべて選択**などの範囲選択ショートカット
- **キャラ素材専用タイムライン区分**：一部解説では、通常アイテム（画像・字幕・動画等）の領域とキャラクター素材専用の領域が画面内で分かれている構成も確認されている（実装依存の可能性、要方針決定）

## アイテム種別と現行データモデルとの対応

| YMM4アイテム種別 | 現行kiritan_rでの相当 | 現状 |
|---|---|---|
| 立ち絵（キャラクター） | `cast`（ADVScene）、`rig.json`（char_006/017のみ） | 部分対応、レイヤー配置概念なし |
| 字幕 | `script`の`narration`/`text`/`conversation.lines[]` | 対応（ただしタイムライン非依存、逐次表示） |
| ボイス | `voice.file`（事前生成wav） | 対応（PROMPT_02b実装済み） |
| 画像・背景 | `script.meta.bg` | 対応（1シーン1枚のみ、タイムライン配置なし） |
| 動画 | なし | 未対応 |
| 図形 | なし | 未対応 |
| 場面切り替え・映像エフェクト | なし | 未対応 |

## アイテム編集パネルの項目（YMM4準拠、根拠あり）

- **全般**：フレーム位置、長さ、レイヤー番号
- 座標・拡大率・不透明度
- 映像エフェクト（複数適用可、将来拡張）
- ボイスアイテム固有：話者・音量・再生速度
- **ボイスアイテムから字幕アイテムを自動生成**する機能が存在（YMM4 v4.16.0.0以降）
- **ボイスアイテムから表情アイテムを自動生成**する機能も存在

## その他の周辺機能（根拠あり）

- **台本読み込み機能**：テキスト台本からキャラ配置・字幕・音声アイテムを一括生成
- **プロファイル設定**：画面サイズ等の設定画面（本システムは1920x1080固定のため優先度低）
- **キャラクター編集**：キャラごとの立ち絵・設定を管理する専用画面
- **保存形式**：ymmp（編集途中データ）/ exo（AviUtl向け出力）。本システムではJSON保存（既存の`_index.json`+イベントJSON方式を流用予定）

## 決定事項

**キャラ素材専用タイムライン区分：分離する。** 立ち絵・ボイス・表情などキャラに紐づくアイテムは専用エリアにまとめ、背景・一般字幕・BGM・SEは別エリアとする。

**台本読み込み・自動生成機能：導入する。** 「キャラ名：セリフ」形式のテキストを流し込むと、字幕アイテム・音声合成アイテム・立ち絵表示がキャラ素材専用エリアに一括自動生成される。その後タイムライン上で微調整する。

**動画・図形アイテム：後回し。** 初期UIには含めない。データモデル上の拡張余地のみ確保すれば足りる。

**ビート/シーンの2層構造を採用する。**
- **ビート**：セリフ1行=1ビート。クリックで区切られる可変長ユニット。ビート内はボイス開始からの相対時間でSE・BGM切替等を細かく指定可。クリックでビート内全アイテムを強制停止し次へ。
- **シーン**：BGM・背景・立ち絵の表示状態など、複数ビートをまたいで持続するもの。ビートの区切りで強制停止しない。
- 現行`script.meta.bg`（シーン相当）+`cast`（シーン相当）+`script`各行（ビート相当）の分け方がこの2層構造の原型。新データモデルはこれを精密化する方向で設計する。

**既存theaterイベントJSONの移行は不要。** 既存イベントは新データモデルで作り直す方針。変換ツールは不要。

**データモデルは根本移行する。** 現行`script`（逐次配列、フレーム位置・長さの概念なし）を廃止し、YMM4的タイムライン（レイヤー×フレーム位置×長さを持つアイテム配列）へ全面移行する。既存の逐次スクリプトへの見た目上のタイムライン風UI付与は不採用。

画面イメージ: `editor_ui_mockup.html`（3ペイン構成：プレビュー／アイテム編集パネル／タイムライン。レイヤー00背景・01立ち絵・02字幕・03ボイスの4トラック、アイテムブロックはフレーム位置＋長さで配置、選択中アイテムの詳細を右パネルに表示）。

**音声の調整・再生成（YMM4準拠、実コード検証済み）：**

現行実装（`tab-events.js`の`_voiceSelect`、`editor.cjs`の`/api/voice/generate`）は話者選択のみ。VOICEVOX audio_queryの`speedScale`/`pitchScale`/`intonationScale`/`volumeScale`/`prePhonemeLength`/`postPhonemeLength`は一切未利用（デフォルト値のまま）。これを以下へ拡張する。

- **キャラクター設定（プリセット）**：話速・音高・抑揚・音量・前後の無音長さを、キャラごとのデフォルト値として登録する。YMM4の「キャラクター設定画面」相当
- **ボイスアイテム個別上書き**：音量のみ、行ごとに上書き可能（YMM4の実仕様に準拠。「ボイスアイテムごと、またはキャラクターごとに音量を設定できる」。話速等は基本キャラ設定に任せる）
- **モーラ（音節）単位のアクセント編集**：今回は対象外。YMM4にも上級者向け別画面として存在するが工数大のため将来課題として記録のみ
- **再生成**：個別行ごとに可能（全体一括ではなく、選択中の1行だけ再生成できる。PROMPT_02bの一括生成ボタンから変更）
