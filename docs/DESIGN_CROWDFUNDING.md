## 1. 全体像

**「ダンジョン」＝ クラファン挑戦と浅層探索の総称。** 拠点付属の迷宮という概念は廃止（§1-2）。

| | クラファン挑戦 | 浅層探索 |
|---|---|---|
| 参加条件 | `maxSoldiers >= 必要ミーム`（フィボナッチ） | 制限なし |
| コスト | **`maxSoldiers = 0`**（ミーム上限の没収） | なし |
| 終了後 | `maxSoldiers` = その回の必要ミーム、`soldiers` も満タン | 変化なし |
| タイムリミット | **40ラウンド** | **20ラウンド** |
| 敵 | クラファン用プールから抽選。**編成人数を対称化** | 浅層探索用プールから抽選。**対称化しない**・クラファンより弱い |
| ゴール | **進捗100%で達成**（進捗ポイント制）。7種（フレーバー＋固有報酬） | なし |
| 余ラウンド | ストレッチゴールとして戦闘継続 | 同左 |
| 報酬 | パラメータ強化 ＋ 好感度 +2 | ミーム ＋ 好感度 +1 |

- **1ターン内で完結**。ゲーム本体のターンをまたがない
- **セーブ不可**（セーブはワールドマップのみ）
- 入口は BottomBar。浅層探索はクラファンの中に置く
- 生放送演出。既存 ADV / theater 基盤で足りる

## 2. クラファン挑戦

### 2-1. コストと参加条件

**没収されるのは `soldiers`（現在値）ではなく `maxSoldiers`（ミーム上限）。**

```
挑戦開始   maxSoldiers = 0  → soldiers も 0
   ↓
挑戦中     ミームを持たない状態で戦う。将軍本体（charHp）のみが戦力
           ミーム < battleCapacity のため常時「参戦」状態＝本体が被弾し続ける
   ↓
挑戦終了   成功・失敗を問わず maxSoldiers = その回の必要ミーム
           soldiers も同値まで満タンで返る
```

**参加条件は `maxSoldiers >= 必要ミーム`。** `soldiers`（現在値）では判定しない。

**必要ミーム はフィボナッチで増加**（挑戦回数はキャラごとに記録）。

| 挑戦回数 | 1 | 2 | 3 | 4 | 5 | 6 | … |
|---------|---|---|---|---|---|---|---|
| 必要ミーム | 300 | 300 | 600 | 900 | 1500 | 2400 | … |

挑戦回数に上限はない。必要ミームの増加が極端な連続挑戦を抑止する。

**設計意図**: `maxSoldiers` 1000 のキャラが初回挑戦すると 300 に下がる（700 減）。報酬（パラメータ強化・ミーム増加倍率）と引き換えに上限を一度リセットする**トレードオフ**。挑戦可能になったキャラは早く挑戦した方が得。

ミーム上限は戦闘によるミーム上限成長（`DESIGN_AFFINITY_BATTLE.md` §8-3）で回復・成長する。

### 2-2. 敵の生成

**クラファン用の敵プールを用意し、そこからランダム選出する。**

- **編成人数はプレイヤー側と対称**。メイン1名で挑めば敵もメイン1名、メイン2＋サブ2なら敵も同構成
- 人数に応じて**選出数を増やす**のが基本
- **何戦かに1度は、選出数を増やす代わりにステータス倍率をかける**（ボス戦の演出）。併用する

敵データは全員仮置きでよい。

### 2-3. ゴール — 進捗ポイント制（2026-08-14 改訂）

**敵を1体撃破するごとに進捗ポイントを加算し、進捗が 100% に達したらゴール達成。**

- 進捗ポイントは**敵ごとに異なる**。強い敵ほど高い
- **こちらが強いほど強い敵が出現する確率が上がる**（§2-3b）
- 強い敵ほど進捗が伸びるため、**強いキャラで挑戦するとストレッチゴールまで到達しやすい**
- 100% 到達後も戦闘は続き、**200% / 300% と累積**する。100% 刻みでストレッチゴールを達成する（**累積型**。進捗はリセットしない）

#### 必要進捗ポイント

**必要ミーム × 参加人数** に比例して決まる（仮置きの係数を1箇所に置く）。

- 挑戦回数が増える → 必要ミームが増える → ゴールが遠のく
- 参加人数が増える → ゴールが遠のく

1vs1 が 4vs4 になれば報酬も4倍になるため、ゴールを4倍遠くすることで釣り合う。**二重の負荷にはならない。**

### 2-3b. 敵の強さ抽選

**プレイヤー側の強さに応じて、上位 tier の敵が出る確率が上がる。**

強さの指標は以下の**併用**。

| 指標 | 内容 |
|------|------|
| **本体パラメータ合計** | `charHp` / `charAttack` / `charDefense` / `soldierAtk` / `soldierDef` 等の合計。ゴール報酬で伸びるため育成度が反映される |
| **必要ミーム** | 過去の挑戦回数の代理。挑戦を重ねたキャラほど強敵に当たる |

**`maxSoldiers` は指標に使えない**（クラファン挑戦中は 0 になるため）。

敵定義には `tier`（強さ帯）と `progressPoint`（撃破時の進捗ポイント）を持たせる。

### 2-3c. ゴール種別

ゴール種別は**7種。今後増える可能性がある**ため、ハードコードせずレジストリで解決する。

| ゴール種別 | 固有の報酬 |
|-----------|-----------|
| **ボーカルソフト化（強化）** | **歌**（`charSong`）。**この種別のみ** |
| **読み上げソフト化（強化）** | 本体パラメータ強化 |
| スタンプラリー | ミーム増加倍率 |
| ライブ | ミーム増加倍率 |
| グッズ制作 | ミーム増加倍率 |
| アニメ制作 | ミーム増加倍率 |
| ゲーム制作 | ミーム増加倍率 |

**全ゴール共通**で本体パラメータ・ミームパラメータの強化が入る。上表は**それに加わる固有分**。

### 2-4. 報酬の対象パラメータ

| 区分 | フィールド |
|------|-----------|
| 本体 | `charHp` / `charAttack` / `charDefense` / `charSong` / `attackCount` |
| ミーム | `soldierAtk` / `soldierDef` |
| 倍率 | **ミーム増加倍率**（新設。§2-5） |

`charSong`（歌）は**ボーカルソフト化でのみ上昇**する。

### 2-5. ミーム増加倍率（新設パラメータ）

**キャラごとに「ミーム上限増加倍率」を持たせる。** 戦闘によるミーム上限成長（`DESIGN_AFFINITY_BATTLE.md` §8-3、基本 +100/戦闘）にかかる倍率。

```
倍率 +10% のキャラ → 1戦闘あたり +110
```

クラファン成功でこの倍率が増加する。スタンプラリー・ライブ・グッズ制作・アニメ制作・ゲーム制作の固有報酬。

初期値・増加幅は未定（仮置きでよい）。

### 2-6. ストレッチゴール

進捗100%到達後も戦闘は続く。**進捗は累積し、200% / 300% と 100% 刻みでストレッチゴールを達成**する。到達ごとに追加報酬（内容は仮置き）。ラウンド切れまで繰り返せる。

### 2-7. タイムリミットと休憩

**単位は `BattleEngineV3` の `round`（ラウンド）。** `state.currentTurn`（ゲーム本体のターン）とは別概念。

1ラウンド ＝ 場に出ている生存ユニット全員が1回ずつ行動する単位（`startRound()` → `nextActor()` が ミーム 昇順で1体ずつ返す → `markActed()` → null になるまで）。

各戦闘の `round` を挑戦セッション全体で**累積**し、残ラウンドから減算する。0 を下回った時点で終了。

| 項目 | クラファン | 浅層探索 |
|------|----------|---------|
| 初期ラウンド | **40** | **20** |

**戦闘ループの合間に「進む」「休む」の2択を出す。**

| 選択 | 効果 |
|------|------|
| 進む | 次の戦闘へ |
| **休む** | **HP 全回復**。**ラウンド 5 消費** |

ミーム は上限0のため回復対象外（回復しても意味がない）。

`battleMode: 'dungeon'` の1戦闘あたりラウンド無制限（`maxRounds = Infinity`）は**維持**。制限は累積側でかける。

## 3. 浅層探索

クラファンと**同じ導線・同じダンジョンフォーマット**を使う。パラメータのみ異なる。

| 項目 | 仕様 |
|------|------|
| コスト | **なし**（ミーム上限は減らない） |
| 参加条件 | 制限なし |
| 敵 | **浅層探索用プール**から抽選。クラファンより弱い。**対称化しない** |
| タイムリミット | **20ラウンド** |
| 終了条件 | ラウンド切れ |
| 報酬 | **ミーム** ＋ 同行キャラとの**好感度 +1** |
| 休憩 | クラファンと同じ（HP全回復・5ラウンド消費） |

### 3-1. アイテム報酬の廃止（P1積み残しの解決）

P1（UI削除フェーズ）で「ダンジョン `rewardItem` 付与停止」が計画されながら未実施のまま残っている。

```js
// DungeonScene.jsx:53-66 → GameContext.jsx:380 で inventory に追加され続けている
const rewardItemId = floorData?.rewardItemId ?? null;
const rewardItem = rewardItemId ? { instanceId: ..., itemId: rewardItemId } : null;
```

アイテム画面のUI経路は削除済みのため、取得物は閲覧不能のまま蓄積している。**`rewardItem` の生成を停止**し、獲得演出も撤去する。`items.json` / `ItemSystem` / `state.inventory` は内部温存原則どおり残置。
