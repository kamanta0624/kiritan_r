# DESIGN_YMM4_SYSTEM — ゲーム内シーン演出システム 全体設計

このファイルが本機能の単一の参照先（SSOT）。設計資料は`docs/ymm4/`以下、完了・破棄済みプロンプトは`docs/archive/`にあるが、「今どこの話をしているか」はまずここで確認する。

---

## 1. 最終ゴール

キャラクターが登場する全画面（ADV会話、ターン開始演出、戦闘シーン等）を、**プリレンダー動画ではなく、テンプレート＋実行時データバインディングでリアルタイム描画する**演出システムを作る。

理由：ダメージ数値・HP等は毎回変わるゲームデータであり、動画に焼き込めない。「動画品質の見た目」を「テンプレート＋実行時データ注入」でリアルタイム描画する必要がある。

## 2. システム構成（4層）

| 層 | 内容 | 本システムでの独自性 |
|---|---|---|
| 1. 描画エンジン | PSDパーツ由来の動く立ち絵。表情差分・自動まばたき・自動口パク・アクション | oovエコシステム流用 |
| 2. データバインディングエンジン | シーンテンプレートの変数スロット（ダメージ数値・HP等）に実行時ゲームデータを注入 | **YMM4に存在しない、本システム最大の独自要素。まだ未着手** |
| 3. 音声パイプライン | VOICEVOX等合成音声＋BGM＋SEのタイムライン編集・再生 | oov/YMM4の設計思想を参考 |
| 4. オーサリングツール | エディタ上でタイムライン・レイヤー・PSD読み込み・音声呼び出しを組み立てるUI | YMM4踏襲 |

## 3. 確定スコープ

- **キャラクター描画基盤**：PSDパーツ方式（oov/psd, oov/PSDTool, oov/aviutl_psdtoolkit流用）。Rive等の外部専用エディタ依存方式は不採用
- **アイテム種別**：動く立ち絵、画像、動画、テキスト（字幕）、音声、図形、場面切り替え（動画・図形は初期UIでは後回し）
- **TTS**：VOICEVOX Engine（ローカルAPI、事前生成方式）を初期実装。他ソフト（AivisSpeech等）は将来拡張の余地を残す設計
- **保存**：JSON、実行時レイヤー合成

## 4. 展開順序

**ボイロ劇場（層1〜4最小実装）** → ターン開始演出 → 戦闘シーン → その他キャラ登場画面

## 6. 決定済み事項の一覧（詳細は各ファイル参照）

### データモデル

- **ビート/シーンの2層構造**：ビート＝セリフ1行、クリックで区切られる可変長ユニット（ボイス開始からの相対時間でSE等を細かく指定可、クリックで強制停止し次へ）。シーン＝BGM・背景・立ち絵の表示状態等、複数ビートをまたいで持続するもの
- 既存theaterイベントJSONの移行は不要（作り直す方針）

### エディタUI

- キャラ素材専用タイムライン区分：分離する（立ち絵・ボイス・表情は専用エリア、背景・一般字幕・BGM・SEは別エリア）
- 台本読み込み・自動生成機能：導入する（テキスト投入→キャラ専用エリアに一括生成）
- 動画・図形アイテムのUI：後回し

### 音声

- キャラクター設定（プリセット）：話速・音高・抑揚・音量・前後無音長さをキャラごとのデフォルト値として登録
- ボイスアイテム個別上書き：音量のみ、行ごとに可能（YMM4の実仕様準拠）
- モーラ単位のアクセント編集：対象外（将来課題）
- 再生成：個別行ごとに可能
