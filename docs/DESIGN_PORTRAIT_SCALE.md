# 立ち絵スケール正規化 — 身長設定表

作成 2026-08-19。用途: PSD→YMM4変換後、キャンバスサイズが作者ごとに異なる問題を、
キャラの公式身長を基準に描画スケールへ換算するための原典表。

## 0. 運用ルール

- `height` は**公式設定のみ**。公式に身長設定が無いキャラは `null`
- `null` のキャラは人間が仮値を決めて `heightManual` 欄に記入する
- 推測値・ファンwiki値・イラスト目測は採用しない
- 出典URLは監査用。数値変更時は出典も更新する

## 1. 換算（未確定・実装時に決める）

```
scale = (height_cm * PX_PER_CM) / psdBodyHeightPx
```

`psdBodyHeightPx` はPSD実測（頭頂〜足元）。

**基準身長 = 155cm**（確定53体の中央値。2026-08-19 人間決定）。
155cm相当のキャラをゲーム画面上で何pxで描くかを1つ決め、`PX_PER_CM = 基準px / 155` で逆算する。
基準pxの値は描画実装時に決める。
