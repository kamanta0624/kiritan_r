# 猫のなわばりあらそい — ルール仕様書

出典: バンダイ公式ルールブック（A4版 rulebook_ja.pdf 全4ページ）／公式サイト猫フィギュアリスト・ダウンロードコンテンツ。
本書は実装用に再構成した内部仕様。原文の丸写しではなくルール要件の整理。

---

## 1. 概要

- 2人用対戦ゲーム。相手のボス猫の**持ちエサを0**にすれば勝ち。
- 猫フィギュア（=ユニット）は台座に**エサ**を載せる。このエサが体力兼コスト。

## 2. 盤面（なわばり）

7エリア構成。

```
        [相手ベースエリア]        oppBase
   [相手左]           [相手右]    oppL / oppR
        [センターエリア]          center
   [自分左]           [自分右]    myL / myR
        [自分ベースエリア]        myBase
```

### 隣接（実装用グラフ）

| エリア | 隣接 |
|---|---|
| myBase | myL, myR |
| myL | myBase, myR, center, oppL |
| myR | myBase, myL, center, oppR |
| center | myL, myR, oppL, oppR |
| oppL | oppBase, oppR, center, myL |
| oppR | oppBase, oppL, center, myR |
| oppBase | oppL, oppR |

> `myL↔myR`（同じ側の左右）は**隣接で確定**（ユーザー判断）。定義は `docs/board.json` の1箇所に集約する。

### エリア制約

- 1エリアに猫は何匹でも入れる。
- **センターエリアのみ**自分の猫1匹・相手の猫1匹まで。**移動途中の通過も不可**。

### 盤外の領域

| 領域 | 所有 | 内容 |
|---|---|---|
| 控え | プレイヤー毎 | 登場前の子猫 |
| 負け猫のたまり場 | プレイヤー毎 | 持ちエサ0で逃げた猫 |
| エサ箱 | プレイヤー毎 | 初期20個 |
| エサ皿 | プレイヤー毎 | 上限6（6個で強制ネコババ） |
| エサ捨て場 | プレイヤー毎 | 効果コストで払ったエサ |

## 3. 猫（ユニット）

| 属性 | 説明 |
|---|---|
| number | S01-01 等のフィギュア番号。同ナンバー制限に使う |
| name / breed | 名前・猫種（猫種はゲーム上未使用） |
| level | 強さ。登場コスト＝レベル、持ちエサ上限＝レベル、攻撃サイコロ回数＝レベル |
| isBoss | ボス猫かどうか |
| frontEffects | オモテ効果（常時自動発動、宣言不要） |
| backEffect | ウラ効果（コストを払い、指定タイミングで使用） |

- 持ちエサはレベルを超えて置けない。
- ボス猫は**移動できない**が攻撃はできる。

## 4. ゲームの準備

1. エサ箱にエサを20個。
2. 子猫を4匹以上用意し控えへ。**同じナンバーの子猫は3匹まで**。
3. ボス猫を1匹用意。
4. エサ箱からボスのレベル分のエサを取り出しボスの持ちエサにする。
5. ボスを自分のベースエリアに置く。
6. じゃんけんで先手（手番プレイヤー）を決める。

## 5. ターン進行

1ターン = スタート → 登場 → メイン → エンド。終了後に手番交代。

### 5.1 スタートフェイズ

- 自分のエサ箱が0なら**タイマン宣言**（強制、断れない）。
- 「スタートフェイズに使う」効果を使える。
- エサ箱から**1〜3個の好きな数**をエサ皿に移す（**必ず1個以上**）。

### 5.2 登場フェイズ

手順:
1. 控えから子猫1匹を選ぶ。
2. エサ皿からその猫のレベルと同じ数のエサを取り、持ちエサにする。
3. 自分のベースエリアに置く。

きまり:
- レベルよりエサ皿のエサが少ないと登場できない。
- レベルより多いエサは台座に置けない。
- 1ターンに何匹でも登場可。1匹も登場させなくてよい。
- **同じナンバーの自分の猫がすでになわばりにいる場合、その番号は登場できない**。

### 5.3 メインフェイズ

自分の猫を[行動]させる。行動 = 猫1匹を選び[移動]と[攻撃]をさせること。

- 行動順は自由。
- 1匹は**移動→攻撃**のセット。**攻撃→移動は不可**。
- 移動だけ・攻撃だけ・行動しないのも可。
- そのターンに登場した猫も行動できる。
- ボス猫は移動不可、攻撃は可。

#### 移動

- ふつうの猫: 1歩（隣のエリア）。
- `移動2`: 2歩、`移動3`: 3歩。
- センターエリアの人数制限は通過時にも適用。
- `とおせんぼ`を持つ猫がいるエリアに相手の猫が移動してきたら、そこで移動を止める。

#### 攻撃

- ふつうの猫: **同じエリア**にいる相手の猫1匹。
- `はなれて攻撃`: 同じエリア**または隣のエリア**の相手の猫1匹。

攻撃手順:
1. 攻撃目標となる相手の猫1匹を決める。
2. サイコロを振る前に、攻撃側が「攻撃時に使う」ウラ効果 → 防御側が「防御時に使う」ウラ効果を使える。優先順位は攻撃側→防御側。**相手が効果を使ったあとに効果を使うこともできる**（応酬可）。
3. サイコロを**レベルと同じ回数まで**振る。`ねこむ`が出たらそれ以上振れない。途中でやめてもよい。「特定の目が出たときに使う」ウラ効果はここで使える。
4. 出たダメージを合計する。
   - `ねこむ`が出ていたら、それまでのダメージに関係なく**攻撃失敗**。
   - `ねこむ`が出ていなければ、ダメージを増減する効果を使える。
   - 最終ダメージ **1以上で成功、0以下で失敗**。
5. 成功なら攻撃目標がダメージを受ける。

##### サイコロ（6面）

| 目 | 面数 | 効果 |
|---|---|---|
| `paw1`（肉球1） | 2 | 1ダメージ |
| `paw2`（肉球2） | 1 | 2ダメージ |
| `x`（バツ） | 2 | 0ダメージ |
| `sleep`（ねこむ） | 1 | 以降振れない・攻撃失敗確定 |

#### ダメージを受ける

ダメージを受ける**プレイヤー**が [猫で受ける] / [エサ箱で受ける] のどちらかを選ぶ。

**[猫で受ける]**
- 攻撃目標の猫の持ちエサをダメージと同じ数減らし、持ち主の**エサ皿**に戻す。
- 持ちエサが0になった猫は逃げる → 持ち主の**負け猫のたまり場**へ。
- ダメージが持ちエサより多い場合、余分は無効。

**[エサ箱で受ける]**
- 攻撃目標の持ち主の**エサ箱**からダメージと同じ数を**エサ皿**に入れる。
- エサ箱が0個のときは選べない。
- ダメージがエサ箱のエサより多い場合、余分は無効。

> どちらもエサが**エサ皿に増える**。エサ皿が6になるとネコババが誘発する。

### 5.4 エンドフェイズ

- 「エンドフェイズに使う」効果を使える。
- 手番プレイヤーを交代し、新たなターンのスタートフェイズへ。

## 6. ネコババ

- エサ皿には6個までしか置けない。**6個以上になるとボス猫が強制的にネコババ**。
- 流れ:
  1. エサ皿のエサが6個以上になる。
  2. エサ皿のエサ6つをエサ捨て場へ。
  3. そのプレイヤーのボス猫のウラ効果（=ネコババ効果、コスト6）が**強制的に**使われる。

> 実装上: ボスのウラ効果は全てコスト6。ネコババ時はコスト支払い済みとして発動する。

## 7. タイマン

- 自分のスタートフェイズに自分のエサ箱が0個のとき宣言。断れない。
- 手順:
  1. なわばりにいる子猫をすべて控えに戻す。
  2. 自分と相手のボス猫をセンターエリアに置く。
  3. 以降、新たな猫の登場・猫の移動は不可。相手ボスへの攻撃は可。エサ箱にエサが残っている側は[エサ箱で受ける]も選べる。
  4. どちらかのボスの持ちエサが0になるまで続ける。

## 8. 勝利条件

相手のボス猫の持ちエサが0になったら勝ち。

## 9. オモテ効果一覧（自動発動）

| キー | 表記 | 効果 |
|---|---|---|
| `move2` | 移動2 | この猫は2歩移動できる |
| `move3` | 移動3 | この猫は3歩移動できる |
| `toosenbo` | とおせんぼ | この猫がいるエリアに相手の猫が移動してきたとき、移動をここで止める |
| `ranged_attack` | はなれて攻撃 | この猫はとなりのエリアの相手の猫も攻撃目標にできる |
| `dice_plus1` | サイコロ+1回 | この猫の攻撃サイコロを1回ふやす |
| `dice_plus2` | サイコロ+2回 | この猫の攻撃サイコロを2回ふやす |
| `damage_plus1` | ダメージ+1 | この猫の攻撃のダメージを1ふやす |
| `damage_minus1` | ダメージ-1 | この猫へのダメージを1へらす |
| `nenai` | ねない | この猫の攻撃のサイコロの`sleep`を`x`に変える（何回でも） |
| `chokugeki` | ちょくげき | この猫が相手の子猫にダメージをあたえたとき、相手は[猫でダメージを受ける]を選ぶ。**ボス猫に対しては無効** |
| `oshidashi` | おしだし | この猫が相手の子猫を攻撃したとき、ダメージにかかわらず攻撃後に攻撃目標の子猫を1歩移動させる。**ボス猫に対しては無効** |
| `renge2` | 2連撃 | この猫が相手の子猫に攻撃した後、続けてもう1回同じ子猫に攻撃できる。**ボス猫に対しては無効** |
| `hangeki` | はんげき | この猫が同じエリアにいる相手の猫に攻撃された後、（まだ逃げていなければ）攻撃してきた猫に攻撃できる。反撃の反撃はない |

## 10. ウラ効果の共通ルール

- 説明に書かれたタイミングで使える。
- 使うときは**コストと同じ数のエサ**をエサ皿か持ちエサから支払う（エサ捨て場へ）。
- コストを支払えない場合は使えない。
- コストが2以上の場合、エサ皿と持ちエサに分けて支払える。
- 特に書かれていないかぎり、1つのウラ効果は**1ターンに1回だけ**。

### タイミングキー（実装用）

| キー | 意味 |
|---|---|
| `instead_of_attack` | 攻撃のかわりに使う |
| `on_attack` | 攻撃時に使う（サイコロ前） |
| `before_attack` | 攻撃前に使う |
| `on_defense` | 防御時に使う（サイコロ前） |
| `on_move` | 移動時に使う |
| `on_dice_sleep` | 攻撃のサイコロで`sleep`が出たときに使う |
| `on_dice_paw2` | 攻撃のサイコロで2ダメージ目が出たときに使う |
| `after_opponent_ura` | 相手がウラ効果を使った直後に使う |
| `nekobaba` | ボス専用。ネコババ時に強制発動（コスト6） |

## 11. センター効果

センターエリアにいる猫は、そのなわばり（プレイシート）ごとに決まった[センター効果]を得る。

| なわばり | センター効果 |
|---|---|
| したまちのなわばり | このエリアにいる猫は「はなれて攻撃」を持つ |
| ねこcaféのなわばり | **効果なし**（公式非公開のため。判明したら `cats.json` に追記） |
| セレブハウスのなわばり | **効果なし**（同上） |

## 12. はじめてセット用ルール（今回は不採用、参考）

- 各プレイヤー子猫4匹・ボス1匹の計5匹で戦う。
- 逃げた猫は負け猫のたまり場ではなく**控え**に置く。

## 13. ハウスルール（公式に記載がなく本実装で確定させた挙動）

1. **エリア隣接**: 自陣の左右（`myL↔myR` / `oppL↔oppR`）は隣接する。
2. **センター効果**: ねこcafé／セレブハウスは効果なし。
3. **`はんげき` と `2連撃` の解決順**: 1回目の攻撃を解決 → 防御側の `はんげき` → 攻撃側の `2連撃`（目標がまだ逃げていない場合）の順。`2連撃` の2回目に対して `はんげき` は再発動しない（「反撃の反撃はない」の準用）。
4. **`おしだし` の移動先**: 押し出した側（攻撃側）が選ぶ。
5. **ウラ効果の応酬の打ち切り**: 攻撃側→防御側の順で交互にパスを選ぶ。**双方が連続でパスした時点で終了**。ウラ効果は1ターン1回制限があるため無限ループしない。

### 公式非公開のまま残る事項

- ねこcafé／セレブハウスのセンター効果（判明したら `cats.json` の `centerEffect` に追記するだけで反映されること）。
