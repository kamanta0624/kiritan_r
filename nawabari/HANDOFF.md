## 作るもの

バンダイ「猫のなわばりあらそい」のルールに準拠した**1人用（対CPU）ブラウザゲーム**。

- 技術: Vite + React + TypeScript。状態管理は外部ライブラリ不要（`useReducer` + Context）。
- 15体すべて収録、通常ルール（子猫4匹以上＋ボス1匹、同ナンバー3匹まで）。
- アセットは**オリジナル**を用意する。バンダイの画像・テキスト画像は一切使わない。猫はSVG/CSS図形またはAI生成画像に差し替え可能な形で `public/cats/{slug}.png` を参照する構造にしておく（画像未配置でもプレースホルダで動くこと）。

## 設計方針（優先順）

1. **ルールエンジンとUIを完全分離**。`src/engine/` は DOM・React に一切依存しない純関数群。エンジン単体で Node からテストできること。
2. **データ駆動**。効果はハードコードせず `docs/cats.json` のキー（`move2`, `chokugeki`, `nekobaba` …）→ 効果ハンドラのレジストリで解決する。新しい猫の追加が JSON 追記だけで済むこと。
3. **最小限**。投機的な抽象化・使わない汎用化はしない。CPU AI は最初は貪欲法（ダメージ期待値最大の行動を選ぶ）で十分。
4. **指示範囲外を変えない**。既存の kiritan_r 配下ファイル・設定に手を入れない。

## 実装順序

1. `src/engine/types.ts` — GameState / Cat / Area / Action の型定義。
2. `src/engine/board.ts` — `board.json` 読み込み、隣接・到達可能エリア計算（センター人数制限と通過制限、`とおせんぼ` を含む）。
3. `src/engine/dice.ts` — サイコロ（`docs/cats.json` の `dice` 定義から面を構築）。seed 可能な RNG を使いテスト可能にする。
4. `src/engine/effects/` — オモテ効果13種・ウラ効果15種のハンドラ。キー→ハンドラのレジストリ。
5. `src/engine/reducer.ts` — フェイズ遷移（スタート／登場／メイン／エンド）、攻撃解決、ダメージ処理、ネコババ、タイマン、勝敗判定。
6. `src/engine/__tests__/` — Vitest。下の成功基準を満たすテストを書く。
7. `src/ai/greedy.ts` — CPU の行動選択。
8. `src/ui/` — 盤面・控え・エサ皿/エサ箱・ログ・ウラ効果使用ダイアログ。

## 成功基準（これを満たすまでループすること）

エンジン:

- [ ] `npm test` が全通過する。
- [ ] 準備テスト: エサ箱20、ボスがレベル分の持ちエサを持ってベースエリアに置かれる。
- [ ] スタートフェイズ: エサ箱→エサ皿の移動が1〜3個に制限され、0個を選べない。
- [ ] 登場: レベル分のエサがエサ皿にないと登場不可。同ナンバーの自分の猫が盤上にいると登場不可。
- [ ] 移動: ふつう1歩／`move2` 2歩／`move3` 3歩。センターに自分1匹・相手1匹を超えて入れず、**通過もできない**。`とおせんぼ` のエリアで移動が止まる。
- [ ] 攻撃: レベル回数までサイコロを振れる。`sleep` が出たら以降振れず攻撃失敗。`nenai` を持つ猫は `sleep` が `x` になる。
- [ ] ダメージ: 防御側が[猫で受ける]/[エサ箱で受ける]を選べる。エサ箱0なら後者を選べない。超過ダメージが無効になる。どちらの場合もエサがエサ皿に増える。
- [ ] 持ちエサ0の猫が負け猫のたまり場に移動する。
- [ ] ネコババ: エサ皿が6に達した瞬間、6個がエサ捨て場に移りボスのウラ効果が強制発動する。
- [ ] タイマン: エサ箱0のスタートフェイズで強制発動。子猫が全て控えに戻り、両ボスがセンターに置かれ、以降登場・移動が禁止される。
- [ ] 勝敗: 相手ボスの持ちエサが0で決着する。
- [ ] 15体すべてのウラ効果に対して、発動タイミングとコスト支払い（エサ皿／持ちエサ、コスト2以上の分割払い）のテストがある。
- [ ] ウラ効果は特記なきかぎり1ターン1回に制限される。

UI:

- [ ] 盤面7エリア、両者の控え・エサ皿・エサ箱・エサ捨て場・負け猫のたまり場が可視化されている。
- [ ] サイコロを振る／振るのをやめるをプレイヤーが選べる。

## ハウスルール（確定済み）

`docs/RULES.md` 第13章が決定事項。勝手に変えないこと。

1. 自陣の左右エリアは隣接する。
2. ねこcafé／セレブハウスのセンター効果はなし（`centerEffect: null` を尊重）。
3. `はんげき` → `2連撃` の順で解決。`2連撃` の2回目に `はんげき` は再発動しない。
4. `おしだし` の移動先は押し出した側（攻撃側）が選ぶ。
5. ウラ効果の応酬は双方が連続パスで終了。

上記以外で仕様が読み取れない点が出たら、勝手に判断せず質問すること。
